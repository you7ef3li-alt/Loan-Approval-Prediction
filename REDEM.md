# Secure Loan Prediction

## About The Project
This is a beginner Machine Learning project that predicts loan approval based on customer information.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib

## What I Did
- Data cleaning and preprocessing
- Handling categorical data
- Training Machine Learning models
- Evaluating model performance

## Machine Learning Models
- Logistic Regression
- Decision Tree

## Dataset
The project uses a dataset containing customer information and loan details.

## Learning Goals
This project helped me practice the basics of Machine Learning workflow, from data preprocessing to model evaluation.
